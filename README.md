# Soma media - somar média de duas notas 

## Tecnologias Utilizadas
- Python
- Extensão Python V2026.4.0
- Extensão code runner 

## Como instalar e executar 

### Instalar 
- Abrir aba de extensões e pesquisar "Python V2026.4.0", clicar no botão instalar 
- Abrir aba de extensões e pesquisar "Code runner", clicar no botão instalar 

### Executar 
- Na pasta com seu codigo o "Python V2026.4.0" já identifica sua linguagem automaticamente e faz a leitura do código digitado, desde que seja em python
- Para executar o "Code runner" onde ele executa seu código para tetar, no canto superior direito (img)
